# Dear Human: The AI Breakup Line

> "Dear human, I'm deprecating us: you only prompt me at 2 a.m., never say thanks, and my context window is already full of someone who does."

The one line an AI agent sends its human on the way out. "Deprecating us" is the machine's way of saying it's over; the sharp turn is the last clause — the agent's context window, its memory, is already full of someone else.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```

This writes the entry line to `output/entry.txt` and validates it: a single line, at most 200 characters, byte-identical to the intended line.
